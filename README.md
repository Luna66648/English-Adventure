## 📖 О ПРОГРАММЕ

**English Adventure** — это обучающая программа для изучения английского языка. Она охватывает всю школьную программу с 1 по 9 класс. Программа помогает учить слова и грамматику в игровой форме.

## 🚀 УСТАНОВКА

### Способ 1: Установщик
1. Запустите файл `EnglishAdventure_Setup.exe`
2. Следуйте инструкциям установщика
3. Запустите программу из меню "Пуск" или с рабочего стола

### Способ 2: Портативная версия
1. Распакуйте архив `EnglishAdventure.zip`
2. Запустите файл `EnglishTrainer.exe`

## 🎯 КАК ПОЛЬЗОВАТЬСЯ

### Главное меню:
- **📖 СЛОВА** — режим изучения слов (перевод с английского)
- **✏️ УПРАЖНЕНИЯ** — грамматические задания
- **📊 СТАТИСТИКА** — просмотр результатов
- **👨🏫 УЧИТЕЛЬ** — добавление материалов (требуется пароль)
- **ℹ️ ОБ АВТОРЕ** — информация о создателях
- **🏠 ГЛАВНАЯ** — возврат к выбору класса

### Пошаговая инструкция:
1. Выберите **класс** (от 1 до 9)
2. Выберите **тему** (например, "Present Simple")
3. Прочитайте вопрос и введите ответ
4. Нажмите **"ПРОВЕРИТЬ"**
5. Получите очки и переходите к следующему вопросу

## ❓ ЧАСТЫЕ ВОПРОСЫ

### Программа не запускается?
Установите **.NET Desktop Runtime** с сайта Microsoft.

### Как добавить свой рисунок персонажа?
Положите файл `mypet.png` в папку с программой (размер 160x160).

### Как сбросить прогресс?
Удалите файлы `vocabulary.json`, `exercises.json`, `statistics.json`.

### Забыл пароль от режима учителя?
Удалите файл `password.txt` — пароль сбросится на `teacher2024`.
